# 活人协议（huoren-protocol）

> 给 vibe coding 产品的活人感协议。总纲：**容器可以设计，内容只能由人来填。**

## 为什么需要它

AI 能把产品做得很"对"，但它的默认输出是所有人的均值——加载提示永远是"加载中…"，报错永远是"出错了，请稍后重试"。而人做的东西里，总有一个地方让用户突然意识到：**这后面有个人**。可能是一句只有开发者会写的话、一个没人要求过的怪念头、一个藏在角落里的小东西。

本协议不是教 AI 假装那个人——伪造的人味比尸体味更有害（一旦用户学会"俏皮 = AI 默认值"，真活人感也被连坐）。它做的是三件事：

1. **给产品留座**：找出所有"允许说人话"的位置（座位），规定这些位置不许拿通用默认值交差；
2. **从开发者身上考古**：立项 prompt、开发聊天记录、commit 里的牢骚——AI 只准转写这些真实材料，不准无中生有；
3. **把挑选权留给人**：AI 执笔，开发者按共鸣过审，零确认不上线。

## 三种模式

| 模式 | 时机 | 一句话 |
|---|---|---|
| A · 先入式 | Day 0，动工前 | 问立项问题、建语料库、开牢骚本 |
| B · 后置滤镜（主推） | 产品做完后 | 扫座位 → 考古 → 分层起草 → 挑选 → 施工 |
| C · 防腐（零输入） | 产品做完后 | 只洗掉默认值，输出中性文案，不假装有人 |

## 三层架构

- **表层（去尸体化）**：低剂量体温，守体面，不做段子；
- **深层（牢骚迷宫）**：真话、骂娘、私人梗，藏起来的东西不伤体面，藏点连成链，只有开发者知道全图；
- **签名位（不可豁免）**：一句亲手确认的原话起步，完整配可以是一段真录的声音、自制表情包、微型小游戏、几个乱动的方块——放在迷宫终点，走完彩蛋链最后一间房是创作者本人。

## 宪法九条（摘要）

1. 执笔不原创：AI 可以转写一个人，不能平均所有人
2. 出处感 > 幽默感
3. 一手 > 二手（自制表情包和录音都是一手）
4. 签名位不可豁免：没有一句亲手确认的原话，不算完成
5. 体面分层：表层守体面，深层随便疯
6. "就是好玩"是合法的立项理由
7. 不伪造：零输入只许中性化，不许个性化
8. 出处可验证：搜不到原句的候选，一律拒收
9. 真录不合成：AI 合成语音/头像冒充本人 = 伪造

## 安装（ZCode）

```bash
git clone https://github.com/LuChen0820/huoren-protocol ~/.agents/skills/huoren-protocol
```

（或下载 zip 解压到同一位置。）放在以下任一位置即可：

```
~/.agents/skills/huoren-protocol/     # 全局，所有项目可用（推荐）
<项目>/.zcode/skills/huoren-protocol/ # 仅当前项目
```

重启会话后生效，之后对 AI 说触发语即可。

**不用 ZCode？** `references/protocol.md` 是协议全文，整份贴进任何 AI 编程工具（AGENTS.md / system prompt / 对话开头）同样生效——skill 只是把它变成一键触发。

## 使用示例

- 「按活人协议模式 B 过一遍」——对做好的产品跑完整滤镜
- 「给这个产品上点人味」/「这产品太像 AI 做的了」——自动触发
- 「防腐模式处理一下文案」——零输入，只做去尸体化
- 「按活人协议开工」——模式 A，从立项问题开始

## 两条诚实的声明

**信任边界**：本协议约束 AI 和流程，约束不了人心——对着假语料点头的人，宪法对他无效。它防无意的伪造，不防有意的伪造。

**零实测**：协议至今没跑过一次真实产品，全部断言都是先验的。它的下一个置信度增量来自你的一次真实运行，不来自更多轮纸面修订。
